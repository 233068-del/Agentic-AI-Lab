# Agentic-AI-Lab

This repository contains the work completed for the AI lab exercises, organized as Jupyter notebooks. The files show the progression of the project from data exploration to model training and final evaluation.

## Project overview
The goal of this lab work was to explore the dataset, understand the problem, train a machine learning model, and evaluate its performance. The notebooks document the process step by step and show how the model improved over time.

## Repository files
- `lab-3-task-1.ipynb` — Initial notebook for the first stage of the lab. This file focuses on loading and inspecting the dataset, understanding its structure, and starting the model-building process.
- `lab-3-task-2.ipynb` — Second stage of the lab. This notebook continues the work by refining the training process, monitoring model performance, and improving the results.
- `lab-3-task-3-final.ipynb` — Final notebook for the completed lab work. It includes the final training/evaluation steps and the overall results of the project.
- `README.md` — Project overview and summary of the work completed in this repository.
